# i18n（任务书 §6-§11/§76）

## 前端

- react-i18next；资源 `frontend/src/i18n/locales/{zh-CN,en-US}.json`；
- language = system / zh-CN / en-US；system 解析：`zh* → zh-CN`，其余 → `en-US`
  （§8，`systemLanguage()` 纯函数 + 测试）；手动覆盖持久化 localStorage
  `asro.language`（UI 偏好，非研究事实）；
- 语言切换不丢状态：i18n 全局实例 + `<html lang>` 同步。

## 后端

- 协议值只用稳定 code/enum（`error_code`/`message_code`/`status`），永不把
  中文文本当协议值（§9）；
- `app/core/i18n.py`：Accept-Language → zh-CN/en-US 归一 + 消息目录（服务端
  生成文本用）；
- 报告渲染目录 `app/core/report_i18n.py`：仅本地化章节脚手架文案；数字、
  claim/thesis 语句、证据摘要为共享数据（§90 一致性测试覆盖）。

## 测试

- 前端：`tests/i18n-theme.test.ts`（system 解析/覆盖优先级）；
- 后端：`tests/test_i18n.py`（zh 变体归一/未知码不崩溃）；
- §90：zh/en 报告数字与引用集一致性（`test_reports.py`）。
